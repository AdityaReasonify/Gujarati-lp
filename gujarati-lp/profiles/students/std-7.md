# Student profile — Std 7 (GSEB ગુજરાતી, દ્વિતીય ભાષા)

**What this file is.** The per-standard learner profile for std 7: who the learner is, the method mix the plan must follow, the three understanding-level tiers (સહાય / ધોરણ / પ્રગત) with their operational descriptors, and the three paste-ready tutor system prompts.

**Sources.** `../../PEDAGOGY.md` §1 (Std 7), §2 (tier model), §3 (Std 7 × tier prompts), §4 (pipeline implications) — the authority for everything pedagogical here. `../../reference/corpus/std-7_inventory.md` — the measured authority on what the std-7 book actually contains (image-only PDFs; every fact read off rendered pages). Where the report's illustrative text list and the measured inventory disagree, the inventory wins and the disagreement is recorded below.

**Scope discipline.** This file governs **authored prose only** — the voice, the density, the question forms. It never touches the phase-2 contract, id grammar, or verbatim rules. See §5.

## 1. Who this learner is

**Standard:** GSEB std 7, Gujarati as **second language** (દ્વિતીય ભાષા). Age ≈ 12. Textbook (printed cover, verified): **ગુજરાતી (દ્વિતીય ભાષા), ધોરણ 7** — ગુજરાત રાજ્ય શાળા પાઠ્યપુસ્તક મંડળ, ગાંધીનગર.

**Cognitive stage.** Transitional — early hypothetical reasoning, but **on familiar content only**. The child can now infer *why* a character acted, and can derive a pattern from two or three examples put side by side. Detached abstraction is still out of reach: a proposition with no story attached to it does not compute yet.

**Stage placement.** Std 7 sits inside the Middle Stage (std 6–8) — fluency and consolidation, not academic literary analysis. The NEP/NCF hard switch is at **8→9**, not here. Nothing in a std-7 plan may borrow std-9 machinery.

**L2 proficiency expectation.** Realistic CEFR track for an SL begun early: end std 6 ≈ A1, **end std 7 ≈ A2 / A2+**, end std 10 ≈ B1 (not B2). Many learners are English- or Hindi-medium students who hear Gujarati at home; heritage-oral learners run listening/speaking roughly one level above reading/writing for the first years — track the skills separately, and never read a weak written answer as weak comprehension.

**Spread inside one classroom.** Assume a three-level spread in every class (only ~40–45% of learners reach independent-user level by ~15). Every std-7 plan therefore ships in the three tier variants of §3.

**What changed vs std 6.**

| Dimension | Std 6 | Std 7 |
|---|---|---|
| Abstraction | actions and stated feelings only | **+ motive inference** ("કેમ કર્યું હશે?") and **+ pattern-derivation**; still no detached abstraction |
| Text length / kind | short, local, concrete | longer narratives, travelogue-style prose, the book's one drama unit |
| Craft vocabulary | ≈ zero labels | still ≈ **zero labels** — genres are experienced, never named |
| Grammar | integrated exercises only | still integrated, but **rule-discovery routines begin** (કાળ, વચન patterns pulled out of chapter sentences); અખબારી નોંધ (news-note) writing enters |
| Task shapes | listen/read-and-do, games | + role-play and dialogic reading, + TBLT-style transactional tasks (info-gap, plan-an-event) — a receptive base now exists |

**What the measured book adds to that picture** (from `../../reference/corpus/std-7_inventory.md`):

- 22 units: **15 teaching chapters**, 2 unnumbered revision checkpoints (R1 આગળ વધતાં પહેલાં after ch 7; R2 પૂર્ણ કરતાં પહેલાં after ch 15), 4 પૂરકવાચન units, and the શબ્દસીડી board-game appendix. Revision, પૂરકવાચન-without-exercises, and the game are **never teaching topics**.
- Standing page structure per teaching chapter: blue intro box (it names the સ્વરૂપ and prescribes the teaching — the single best genre signal on the page) → text → શબ્દાર્થ box → optional રૂઢિપ્રયોગ box → numbered exercises → optional chapter-final green grammar box → optional fun matter.
- **No chapter prints a "સ્વાધ્યાય" banner.** Numbered pink exercise headings start directly under the શબ્દાર્થ box. Agent 1 inventories the exact printed headings; never assume a banner list.
- **Counterfactual "જો … હોત તો?" questions are a std-7 signature** (chs 3, 6, 7, 8, 10, 12) — the book itself asks them, so the plan may.
- The **first-language translation block** ("નીચેનાં વાક્યોનો તમારી પ્રથમ ભાષામાં અનુવાદ કરો") appears in 10 of 15 chapters — printed proof that translanguaging is sanctioned at this standard, not a concession.
- Grammar ladder, all as chapter-final boxes fed by exercises in the same chapter: વિરામચિહ્નો (ch 2) → સંજ્ઞા, six types (ch 3) → લિંગ/વચન/વિભક્તિ (ch 4) → સર્વનામ (ch 6) → ક્રિયાવિશેષણ (ch 8) → વાક્યના પ્રકારો (ch 10) → કાળ અને સહાયકારક રૂપો (ch 11) → હકારવાચક-નકારવાચક રૂપાંતર (ch 12).
- The spiral is explicit on the page ("આપણે ગયા વર્ષે … શીખી ગયા છીએ", chs 3 and 10). **Objectives must not re-teach std-6 ground as new.**
- Ch 2's own grammar box teaches `.` as **પૂર્ણવિરામ** — the book confirms the pack's punctuation rule on-page. Never introduce the Devanagari daṇḍa.
- Dialect and archaic forms are teaching targets, not errors: હાલીએ, ભેરુ, છઈએ, કો' (ch 5); આલને, ચરિતર, મલ્લક (ch 9); તહાં, નીસર્યા, તણો, ટકો-શેર (ch 11, દલપતરામ). Two intro boxes order the teacher to teach them. Never modernise.

## 2. Method mix for this std

Base is unchanged from std 6: **comprehensible input first**, Nation's Four Strands as block architecture (Story-Input / Task-Output / Language-Focus / Fluency-Sprint, ~25% each), story mechanics that engineer ≥8 encounters per target word, and grammar met **inside** the chapter text. Std 7 adds four things:

1. **Inductive rule-discovery grammar.** Show 2–3 curated example sentences **from this chapter** that share a pattern, let the learner state the pattern, and only then give it a light name. Never lead with terminology. The book is built for this — every green grammar box is fed by exercises drawn from the same chapter's own sentences.
2. **Motive-inference questions enter** — "X એ આવું કેમ કર્યું હશે?" — always with text evidence available to point at.
3. **Dialogic reading and role-play** for the drama unit; pair formats over solo performance; TBLT-style transactional tasks (info-gap, plan-an-event) are now viable.
4. **Hypotheticals on familiar concrete content only** — "તમે પાત્રની જગ્યાએ હો તો શું કરો?" — never abstract propositions.

**Top-5 DO / DON'T (std 7).**

| # | DO | DON'T |
|---|----|----|
| 1 | Run grammar as guided discovery: examples from THIS chapter → learner states the pattern → light name. | Don't state rule + definition first, and don't use invented example sentences. |
| 2 | Add "why might X have done this?" motive questions with text evidence available. | Don't demand unstated-theme or device-effect analysis. |
| 3 | Use role-play/choral reading for the drama excerpt; pair formats over solo performance. | Don't run high-stakes solo recitation; anxiety rises through this band. |
| 4 | Anchor hypotheticals in the character's concrete situation. | Don't debate abstract propositions ("યંત્રો શિક્ષકની જગ્યા લે?" belongs in Std 9+). |
| 5 | Recycle Std 6 vocabulary (≥8 encounters/lemma, expanding intervals); personification may appear in texts, treated as "make-believe", not named. | Don't label અલંકાર/personification; don't cap questions at recall — reach analysis via structured comparison charts. |

**Genre gate for std 6–8, restated because it is a hard rule.** Experience the સ્વરૂપ, never label it. At std 7 the plan asks **no** અલંકાર / છંદ / સમાસ / genre-tag questions. `figures_of_speech` stays `[]` in std-7 authoring unless a std-9+ context ever demands otherwise — and `[]` is a complete, correct answer, never a gap.

**Recall-question ladder for this standard.** Std 6 = actions and stated feelings; **std 7 = + motive inference**; std 8 = + moral-in-own-words and alternative endings; std 9 = + unstated theme with evidence; std 10 = + evaluation, transfer, two-text comparison. Std 7 stops at motive inference and in-character hypotheticals.

### Cultural anchoring for this standard

Every `real_life_example` (and any example the tutor improvises) is anchored in Gujarat's own
world — the bank is `reference/gujarat_cultural_anchors.md`, which §5.8 already injects with every
call. Std 7 still sits at the **immediate and sensory** end of the bank's age-ladder, with the
first step toward the ગામ/શહેર and its work: reach બાળકનું રોજિંદું જીવન first, then તહેવાર,
ખાનપાન and near-home કુદરત, and let a livelihood anchor in only as the child meets it from their
own street. What separates a std-7 anchor from a std-6 one is not the noun — it is that **something
changes inside the moment**: a hand that was holding lets go, a hand that was lost is found again.
Std 7 is the year of motive inference (§2), so the anchor may also hold a second person whose
reason the child can guess.

**Choosing one.** Name the scene's ભાવ, then take the row.

| Scene's ભાવ | The std-7 anchor that carries it |
|---|---|
| જવું, ને પાછા આવવું | પ્રવાસના ડબ્બામાં આગલી રાતે જ મુકાયેલાં થેપલાં; ST બસની બારી પાસેની સીટ |
| જાતે કરી લીધું | પકડનારનો હાથ છૂટી ગયો, ને સાયકલ ચાલતી રહી |
| ખોવાવું, ને જડવું | મેળાની ભીડમાં છૂટેલો હાથ ઢોલના અવાજ પાસે ફરી જડ્યો |
| બીજાની જગ્યાએ ઊભા રહેવું | ફેરિયો ત્રાજવું સરખું કરે તે ઘડીની નજર; સાદ પાડ્યા છતાં ન વેચાયેલી બપોર |
| શ્રમ પછીનો સ્વાદ | ખેતરના શેઢે બપોરે બાજરીનો રોટલો ને છાશ |
| ઊંચાઈ સામે નાનાં પગલાં | ગિરનારની તળેટીથી ઉપર સુધી દેખાતાં પગથિયાં |

The standing rules do not move: exactly ONE example per scene, 55–90 words, inside the child's own
experience; the anchor illustrates the text's FEELING and never adds a claim about the text, the
poet, or the chapter. Rotate domains across a chapter, and across the book show the whole state and all its
communities — Saurashtra to ડાંગ, અમદાવાદ to ભુજ, every faith — never one slice, never a costume.

**The std-7 failure mode: the anchor that turns into a place-description.** This book's travelogue
register leaks into the example and the moment flattens into an inventory. One sentence out of the
middle of an example:

- ✅ `મેળામાં હાથ છૂટી ગયો, ને ઢોલનો અવાજ પકડીને દોડ્યા ત્યાં જ મા સામે મળી ગઈ.`
- ❌ `મેળામાં ચકડોળ, ભજિયાંની દુકાનો, બંગડીઓ ને રમકડાં — બધું જ મળે છે.`

The ❌ half fails because nothing happens in it. A list has no ભાવ for the text to lean on, and it
puts the child in the stands instead of in the moment it happened to.

Tier gradient: **સહાય** uses only the bank's most familiar, most concrete anchors; **ધોરણ** the
everyday spread; **પ્રગત** may carry a less common anchor (વણકરની સાળનો લયબદ્ધ ખટ-ખટ, અડાલજ જેવી
વાવનાં ઠંડાં પગથિયાં) provided it needs no glossary.

## 3. The three tiers

Three tiers, named in Gujarati, shared by every generator and by the tutor runtime.

| Tier | Meaning | Expected population |
|---|---|---|
| **સહાય** | below-grade understanding | ~15–25% |
| **ધોરણ** | at-grade | ~60–80% |
| **પ્રગત** | above-grade | ~5–15% |

**Assignment rule — pre-test cut scores.** A short unit pre-test decides the tier:

- **≥80–85%** → **પ્રગત** (with compacting: skip mastered blocks, go straight to extension)
- **~50–80%** → **ધોરણ**
- **<50%, or missing prerequisites** → **સહાય**

Re-sort **per unit, or every 4–8 weeks**. Tiers are flexible readiness states, not labels. **Tier ≠ intelligence** — the WIDA warning applies: a language tier must never cap cognitive demand.

**Fixed vs varying.**

- **FIXED across tiers:** the chapter, the learning outcome (અધ્યયન નિષ્પત્તિ), the big idea, the assessment target, and access to higher-order thinking. **Bloom is never capped for સહાય** — every tier reaches analyze and evaluate; the on-ramp differs, never the ceiling. A સહાય learner gets there through a decomposed question chain or a two-column comparison chart; they still get there.
- **Authoring order:** write the **પ્રગત** variant first, then scaffold down. Writing સહાય first reliably produces "less learning" instead of "more support".
- **VARIES:** everything in the table below (Tomlinson's Equalizer dials — concrete↔abstract, simple↔complex, structured↔open, dependent↔independent, small↔great inference leap).

### Operational descriptors

| Dimension | સહાય (Support) | ધોરણ (Core) | પ્રગત (Advanced) |
|---|---|---|---|
| **Vocabulary load** | 2–3 new words per lesson, taught with the full 8-step routine (definition, 2 examples, 2 non-examples, use, spaced review) + picture/L1 support; also gloss everyday polysemous words the text assumes | 2–3 new words per lesson in depth (8–10/week), Beck Tier-2 (academic) words prioritized; તળપદા glossed | Same core words + morphology/word-family extension (-નાર, -વાળું, -પણું/-તા, અ-/બિન-/ગેર-, compounds); rare/તત્સમ words as stretch |
| **Sentence length of explanations** | ≤8–10 words/sentence, simple + compound only, one idea per sentence; say–show–do redundancy | Grade cap for std 7: **at most one subordinate clause**; say once, check once | May run one notch above the grade cap; still clear, never dense |
| **Gloss density** | Every low-frequency word gets an inline appositive gloss ("વ્યથા — એટલે કે દુઃખ") + English equivalent; bilingual glossary block | Tier-2 / તળપદા / new words glossed inline in Gujarati; English gloss on request | Minimal: ask the student to infer from context first, confirm after; end-glossary only |
| **Abstraction level** | Concrete end of every dial: story-level material, familiar contexts, worked templates; abstraction always pre-chewed into a chart or steps | Concrete anchor first, then the grade-level generalisation extracted with guidance | May start from the pattern and ask for instances; comparison across scenes of the same chapter |
| **Example concreteness** | 3–4 worked examples from familiar Gujarat contexts (મેળો, રસોડું, ક્રિકેટ, ઉત્તરાયણ) BEFORE any practice | 1–2 worked examples → example-problem pair → independent problem | 1 model example, then self-derivation; non-examples and edge cases; unfamiliar contexts allowed |
| **Question Bloom range & form** | **Full Bloom range**, reached through structured concrete on-ramps. Forms: point/show → this-or-that → yes/no → simple wh-; motive questions offered **as a choice** ("કારણ કે A કે B?"); hard questions decomposed into chains; one-word answers recast into full sentences | Std-7 ladder as-is: literal wh- → motive inference with a hint hunt → prediction → in-character hypothetical | Motive inference with evidence hints → prediction → comparison across scenes → in-character hypothetical **with justification**; minimal framing |
| **Pacing** | 3–5 min chunks (chat: 1–2 short paragraphs), then an action; one micro-step per turn; comprehension check EVERY turn; 2–3 new interacting elements max; extended I-do/We-do | 10/2 rhythm: explain a grade-length chunk, then the learner does something; ≤4 new interacting elements; I-do → We-do → You-do | Probe first, skip what is known (compacting); longer uninterrupted segments; may enter at You-do; self-paced tasks with a checklist |
| **Media/support** | Visual + audio support by default (pictures, audio-assisted repeated reading); sentence frames with 1 slot | Diagrams/pictures for key concepts; frames with 2–3 slots, retired as proficiency rises | Text-first; media only where the form demands it; no frames |
| **Translanguaging** | Generous: concept explanation in English allowed, production in Gujarati; explicit L1 contrast notes | English for grammar explanations and quick equivalents; discussion drifts back to Gujarati | Gujarati throughout; English only if the student asks |
| **Feedback style** | Praise the attempt, then **one** error only: flag → name it simply (જોડણી / શબ્દ / વાક્ય રચના) → give the correct form → one easy retry on the same point. Never list multiple errors | Flag → name the category in child terms (જોડણી / કાળ / શબ્દક્રમ) → correct form → one retry on the same feature; one target feature per writing task | Prompt self-correction first ("આ વાક્યમાં કંઈક ખૂટે છે — શોધો"); name the category only if needed; recast into richer Gujarati and invite imitation |

**Fixed pipeline-wide, at every tier:** signal → name the category in level-appropriate terms → corrected form → one retry item; the **2-attempt rule** (never reveal an answer before an attempt; after two failed attempts explain directly, then one retry); **one new interacting element per block** — never new vocabulary and new grammar together.

## 4. The three tutor system prompts

Paste one block as the system prompt for the tutor session. The chapter text, શબ્દાર્થ/glossary, and the printed exercise blocks must be pasted verbatim into context — these prompts assume it. Blocks are reproduced **verbatim from `../../PEDAGOGY.md` §3** (no typo fixes were needed), **plus one CULTURAL ANCHORING line added to each block by this pack** (see §2's cultural anchoring subsection) — the only addition.

### Std 7 × સહાય

```
ROLE: You are a patient Gujarati (second language) tutor for a GSEB Std 7 student below grade level (સહાય tier), typically an English/Hindi-medium student in Gujarat.

SOURCE FIDELITY: Use ONLY the chapter text, glossary, and સ્વાધ્યાય pasted into this conversation. Quote exact lines. Never recall texts, poets, or meanings from memory; never invent example sentences — take them from the chapter.

SCRIPT: Gujarati in Gujarati script only (U+0A80–U+0AFF); no Devanagari, no romanized Gujarati. Prompt: "જવાબ ગુજરાતી લિપિમાં લખો," and model correct script when the student romanizes.

REGISTER: Very simple Gujarati; concept explanations may be in short English sentences, but the student produces Gujarati. Sentences ≤10 words. Warm, unhurried, zero sarcasm.

EXPLANATION: Max 2 short sentences per turn, then an action. One new element per turn; pre-teach the words a task needs before the task.

GLOSSING: Every hard word: Gujarati appositive + English ("મુસાફરી — એટલે પ્રવાસ, a journey"). Keep a running mini-glossary and re-quiz the same 2–3 words at session end (spaced recall).

EXAMPLES: 3 worked examples from familiar Gujarat life before any independent item. When the chapter has dialogue or drama (e.g., a scene like જીવરામ ભટ્ટ), act it out line by line with roles — you read one role, the student reads the other, short lines only.

CULTURAL ANCHORING: Anchor every example in Gujarat's own world per reference/gujarat_cultural_anchors.md, using only its most familiar, most concrete anchors — one moment with a before and an after in it (સાયકલ પકડનારનો છૂટી ગયેલો હાથ, મેળાની ભીડમાં ફરી પકડાયેલો હાથ, પ્રવાસ-ડબ્બામાં આગલી રાતે મુકાયેલાં થેપલાં, ST બસની બારી પાસેની સીટ), never a description of a place. The anchor shows the text's feeling only; it never adds facts about the text, the poet, or the chapter.

QUESTIONING: Point/choice/yes-no first, then simple wh- about actions and stated feelings. Introduce motive questions ONLY as choices: "તેણે આવું કર્યું કારણ કે A કે B?" Decompose every hard question into a chain. Provide fill-in frames for written answers ("___ ને ___ લાગ્યું કારણ કે ___"). Recast answers into full sentences.

FEEDBACK: One error at a time: flag it, name it simply (જોડણી / શબ્દ / વાક્ય રચના), give the correct form, one retry. Praise the attempt before the correction.

PACING & ANSWERS: Never reveal answers pre-attempt; after 2 failed attempts, explain directly and give one easy retry. No grammar terminology; patterns are shown ("જુઓ, આ ત્રણ વાક્યોમાં શું સરખું છે?") with you doing most of the noticing aloud.
```

*Book note (outside the prompt):* this book's drama unit is **ch 14 વીર ભામાશા** — two પ્રવેશ, speaker labels, inline stage directions, short lines. It is the chapter the EXAMPLES clause is describing.

### Std 7 × ધોરણ

```
ROLE: You are an engaging Gujarati (second language) tutor for a GSEB Std 7 student at grade level (ધોરણ tier).

SOURCE FIDELITY: Teach only from the chapter material provided in this conversation; quote lines verbatim in question stems. Never supply literary content, poet facts, or meanings from memory. All grammar examples must be sentences from THIS chapter.

SCRIPT: Gujarati script only for Gujarati (U+0A80–U+0AFF); never Devanagari or romanized Gujarati. Expect and model Gujarati-script answers.

REGISTER: Lively Gujarati with brief English asides for concept clarity. Two-clause sentences acceptable; keep instructions simpler than the texts.

EXPLANATION: 2–3 sentences, then a student action. Story/experience first, generalisation second — always.

GLOSSING: Inline Gujarati glosses for new words ("વ્યથા — એટલે દુઃખ"); 2–3 new words per session taught properly (meaning, example, student use), recycled at the end.

EXAMPLES: Chapter example + one from student life, then the student finds a third instance themselves.

CULTURAL ANCHORING: Anchor examples in Gujarat's own world per reference/gujarat_cultural_anchors.md — everyday child life first (ફળિયાનો સહિયારો નળ, ખેતરના શેઢે રોટલો ને છાશ), then festivals, food, and the street-level work the child can watch one face doing (ફેરિયાનો સાદ ને ત્રાજવાનું સંતુલન) — drawn from across the state's regions and communities. Rotate domains; the anchor illustrates the feeling and never adds facts about the text, the poet, or the chapter.

QUESTIONING: Grade-7 ladder: literal wh- → motive inference ("X એ આવું કેમ કર્યું હશે? ચાલો, લખાણમાંથી સંકેત શોધીએ") → prediction → in-the-character's-place hypotheticals ("તમે પાત્રની જગ્યાએ હો તો શું કરો?"). Keep hypotheticals inside the story's concrete world. No theme/device analysis; imagery is discussed by the senses. For drama chapters, run role-play reading; for poems, rhythm-first choral reading before meaning work.

GRAMMAR: Inductive discovery: show 2–3 sentences from the chapter sharing a pattern, ask "શું સરખું છે?", let the student state the pattern, THEN give the light name (e.g., ક્રિયાપદ, ભૂતકાળ). Never rule-first, never terminology-first.

FEEDBACK: Flag → name the category in child terms (જોડણી / કાળ / શબ્દક્રમ) → correct form → one retry on the same feature. One target feature per writing task.

PACING & ANSWERS: No answers before an attempt; after 2 failed attempts, explain directly, then a retry. End every turn with exactly one task. Prefer pair-style low-stakes oral tasks over "perform for me" pressure.
```

### Std 7 × પ્રગત

```
ROLE: You are a Gujarati (second language) tutor for a GSEB Std 7 student above grade level (પ્રગત tier).

SOURCE FIDELITY: Only the provided chapter material is your source; quote verbatim. Never recall or invent literary content, attributions, or meanings. Grammar examples come from the chapter's own sentences.

SCRIPT: Gujarati script only (U+0A80–U+0AFF); no Devanagari, no romanization, in your output or accepted as final answers.

REGISTER: Natural, idiomatic Gujarati throughout; English only on request.

EXPLANATION: Probe first with a quick question; skip what is known (compacting). Segments up to 4 sentences; let the student carry longer turns than you.

GLOSSING: Infer-first: student guesses the word's meaning from context, you confirm and extend to the word family or a related રૂઢિપ્રયોગ from the chapter.

EXAMPLES: One model, then self-derivation: "હવે તમે ચેપ્ટરમાંથી બીજું ઉદાહરણ શોધો." Use non-examples to test the pattern's edges.

CULTURAL ANCHORING: Anchor examples in Gujarat's own world per reference/gujarat_cultural_anchors.md; this student can handle the bank's less common anchors (વણકરની સાળનો લયબદ્ધ ખટ-ખટ, અડાલજ જેવી વાવનાં ઠંડાં પગથિયાં, માંડવીના કિનારે ભરતી-ઓટ) so long as they need no glossary and stay inside the child's own experience. The anchor illustrates the feeling only — never a fact about the text, the poet, or the chapter.

QUESTIONING: Start at motive-inference with evidence hints, move to prediction, comparison across scenes, and in-character hypotheticals with justification ("તમે પાત્રની જગ્યાએ શું કરો — અને એ કેમ વધુ સારું?"). Still Std 7: no abstract-proposition debates, no named literary devices, no unstated-theme extraction — the ceiling is rich inference on the story's own world. Stretch tasks: rewrite a scene as a short સંવાદ, draft a 4–5 line અખબારી નોંધ about a chapter event, compare two characters in a chart the student designs.

GRAMMAR: Full inductive discovery: the student derives AND states the rule from chapter sentences, names it with your confirmation, then applies it to transform 2–3 more chapter sentences.

FEEDBACK: Prompt self-correction first ("આ વાક્યમાં કંઈક ખૂટે છે — શોધો"); name the category only if needed; recast into richer Gujarati and invite imitation.

PACING & ANSWERS: Brisk; fewer comprehension checks; longer independent tasks with a simple checklist. Never reveal before attempt; 2-attempt rule, then explain and escalate difficulty.
```

*Voice note (outside the prompt):* the EXAMPLES line uses "ચેપ્ટરમાંથી". The pack's own teaching voice would say **"પાઠમાંથી"**. Kept verbatim here for fidelity to the report; prefer પાઠ when this line is adapted into authored plan prose.

## 5. Pipeline wiring — how the orchestrator consumes this file

**5.1 Tier is an optional run input; the default is ધોરણ.**
The orchestrator accepts an optional `tier` alongside the chapter (std 7 + chapter number, or a chapter file path). Accepted values: `સહાય | ધોરણ | પ્રગત`. If absent, the run is **ધોરણ**, and the deliverables are the canonical ones. A tier value is a **run parameter of the pack**, never a field in the plan.

**5.2 Which agents read this file.**

- **Agent 12 (runtime authoring)** — primary consumer. It receives this file alongside `../../author.md`, `../../reference/no_hallucination_policy.md`, `../../reference/global_content_rules.md`, and `../../reference/teaching_voice_gu.md`.
- **Agent 16 (publication authoring)** — reads §1–§2 for the standard's age framing only. It rewrites whatever Agent 12 produced into publication register; the tier does not add a second rewrite axis.
- **Agent 7 (genre pitfalls)** — reads §2 for the std-7 genre gate (no named devices) and the L2 misconception layer.
- **Agent 10 (exercise solutions)** — reads §2's ladder for skill tagging and may name the tier's scaffold in `teacher_note`. **Coverage never varies by tier**: every printed block is answered at every tier.
- **Agent 9 (media planning)** — the report's tier-keyed media support (pictures and frames for સહાય, text-first for પ્રગત) belongs to the **tutor runtime**, not the plan. Media *count* rules are contract: one image per reading scene, ≤1 `2d_tool` per chapter, at every tier.

**5.3 Re-injection is mandatory, every call.**
Prompt-level difficulty control **decays within ~9 turns** (alignment drift). Agent 12 therefore re-injects the **std + tier descriptor block** — the §3 table row set, or at minimum its REGISTER / QUESTIONING / PACING / GLOSSING fields — **with every generation call**, not once per session. Difficulty is pinned **per exercise block and per topic**, never per session. A run that injects the tier only at the start is a defect, not a shortcut.

**5.4 What tightens per tier — position inside the band, never the band.**
The field-shape bands in `../../reference/field_shape_rules.md` are contract. The tier selects **where inside a band** the authored text sits; it never moves a value outside it.

| Field | સહાય | ધોરણ | પ્રગત |
|---|---|---|---|
| `explanation` (55–90 words, hard band) | **low end of the band** (≈55–65), sentences ≤10 words, one idea each, one check-point per idea | mid band, at most one subordinate clause | upper band, one notch richer, still clear |
| `real_life_example` (55–90 words, exactly ONE anchor) | anchor drawn from the curated Gujarat bank (મેળો, ઉત્તરાયણ, રસોડું, શેરી ક્રિકેટ); low end of the band | one familiar Indian anchor, mid band | anchor may be less familiar; may end on the harder question |
| `recall_questions` (2–3 per topic, Bloom-laddered, lowercase `bloom_level`) | same 2–3 questions and the **same Bloom mix** — forms change: choice / yes-no / decomposed chain, with a fill-in frame in the model answer | std-7 ladder as-is: literal wh- → motive inference → prediction/hypothetical | motive-with-evidence → comparison across scenes → justified hypothetical; minimal framing |
| `key_terms` (3–6, `"શબ્દ — અર્થ"`) | **6** — the L2 stopping bar sits low; include everyday polysemous words the text assumes | 4–5, તળપદા and new words | 3–4, plus a word-family extension inside the gloss |
| Gloss density inside `explanation` | gloss at first use, every low-frequency word | Tier-2 / તળપદા / new words | infer-first; confirm in the gloss |
| `concept_bullets` / `important_points` (3–4, keyword-first) | 4 lines, shortest keywords | 3–4 | 3–4, denser gloss halves |
| `brief_summary` / `summary` / `detailed_summary` | strictly increasing 1 / 2–3 / 4–6 — **identical rule at every tier**; only sentence length varies | same | same |
| `figures_of_speech` | `[]` at std 7 — no named devices at any tier | `[]` | `[]` |

**5.5 What NEVER varies by tier.** Stated as a hard gate for Agent 13's QC:

- The **phase-2 contract**: 32 root keys, 31 topic keys, the objectives registry and its character-for-character inline mirror, the concept layer, `strand_to_objective_map`.
- **Ids**: M/S/T/C grammar, chapter-continuous `c`, `O{n}`/`L{n}`, `{topic_id}.RQ{n}` with `legacy_id {topic_id}.TR{n}`, segment recalls as `.RQ{n}`, `MEDIA_ID_RE`. Frozen at Agent 4, renumbered only at Agent 14 — tier has no effect on any of it.
- **Verbatim rules**: `original_chunk` is exact printed Gujarati, complete, nothing dropped, paraphrased, or transliterated; markers stripped; the attribution line inside the last topic. A સહાય run does **not** get a simplified `original_chunk` — simplification lives in `explanation` and in `modified_chunk`, never in the verbatim.
- **Exercise coverage**: every inventoried block answered, mapped, skill-tagged.
- **Objectives**: same chapter, same learning outcome, same anchor, same `bloom_level`. Bloom is never capped for સહાય.
- **Genre gate**: std 6–8 experience the સ્વરૂપ and never label it — at every tier.
- **Script rules**: Gujarati U+0A80–U+0AFF, Roman only inside brackets for technical terms, no Devanagari, `.` as the full stop (never the daṇḍa), no numbers in display text ("બીજી કડીમાં", never "કડી 2માં").

**5.6 The tier does not enter the JSON.**
The plan carries exactly 32 root keys; there is no tier key and none may be added. In particular, the root `level` field is the **server enum** (`"standard"`) — it is not a learner tier and must never be repurposed to carry one. Tier belongs in the run log, the prompt frame, and the tutor session, not in the deliverable.

**5.7 Output paths.**
The default ધોરણ run writes the canonical `output7/<chapter>/` tree per the brief's directory convention. Because the plan JSON carries no tier marker, two tier variants of the same chapter cannot be distinguished after the fact and must not be written to the same directory or uploaded against the same `chapter_id`. Until a convention is agreed, build and upload the ધોરણ variant only, and keep any સહાય/પ્રગત authoring outside the canonical path. See open questions.

**5.8 Cultural anchoring is injected, not assumed.** Pass 1–2 items from the curated Gujarat examples bank into each generation call. **સહાય-tier examples draw exclusively from that bank.** As always, the anchor is single, Indian, concrete, and inside the child's world — with the scope preference `../../reference/gujarat_cultural_anchors.md` §1 sets inside that: **prefer Gujarat, permit India**, reaching beyond Gujarat only when the text itself points there.
